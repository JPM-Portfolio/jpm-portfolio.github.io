Instructional Video: Solving Linear Equations

An instructional design project demonstrating the development of a short educational video using structured explanations, visual emphasis, and independent learner practice.

Project Overview

This project involved designing and developing a short instructional video aimed at teaching learners how to solve basic linear equations.

Learning Objective

The goal was to enable learners to solve basic linear equations by following a clear, step-by-step method.

Instructional Design Approach

I applied a structured instructional approach, beginning with a clear learning objective, followed by a worked example and step-by-step guidance.

The content was sequenced to gradually build understanding, with each operation logically following the previous one.

Visual emphasis was used to draw attention to important mathematical operations, while an independent practice question encouraged learners to apply the method.

Development Process

Visual slides were created using Microsoft PowerPoint to support each stage of the explanation.

Audio narration was recorded to guide learners through the process.

Adobe Premiere Pro was used to edit the final video, combine narration with the visual content, and add visual emphasis to important steps.

Key Features

  • Clear learning objective at the start
  • Step-by-step explanation of the process
  • Worked example to support understanding
  • Visual emphasis on mathematical operations
  • Independent learner practice question
  • Recap to reinforce learning
